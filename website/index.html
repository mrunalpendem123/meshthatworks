meshthatworks

adaptive collective inference on heterogeneous edge devices

A small cluster of consumer devices — phones, laptops — each running a complete small language model from a different model family. A prompt is answered by all of them in parallel. The system measures where the collective is uncertain, decides which single node is best placed to resolve that uncertainty, sends one targeted follow-up to that node only, and synthesizes a final answer. No cloud. Nothing leaves the local network.

Every existing uncertainty-routing system assumes a stronger model exists to escalate to. This one does not. There is no oracle. Selection is among equals — on complementary strengths, not a capability ordering — and the extra pass costs battery on a device someone is holding. The headline metric is quality per joule.
not model shardingNot one large model split across devices. Every node runs a whole model and can answer alone.
not mixture-of-agentsNo blind aggregation of everything. Diagnosis first, then exactly one extra inference where it counts.

the mechanism

prompt
  → fan out to N nodes, K samples each
  → semantic clustering (bidirectional entailment)
  → cross-node divergence           → is there a gap?
  → per-node entropy, calibrated    → who resolves it?
  → cost check                      → is it worth the battery?
  → one targeted second inference
  → synthesis (node-class model only)

The gap detector is semantic entropy (Farquhar et al., Nature 2024). It normally costs 5–10× compute for the extra samples — but a mesh generates multiple answers in parallel anyway, so the expensive part is free by construction.
